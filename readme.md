# DigiDocs (digidocs.com)

DigiDocs is a secure, citizen-centric digital service platform designed to help users officially download and manage their government-issued identity documents via **DigiLocker API** and print them into high-quality **PVC Smart Cards**.

## 🚀 Core Features
* **Secure Login:** User authentication using Mobile OTP via DigiLocker.
* **Official Document Retrieval:** Instant download of Aadhaar, PAN Card, Driving Licence, and Ration Card.
* **Automated PVC Layout:** Automatically converts fetched official JSON/XML document data into formatted Front and Back JPG images (Standard CR80 size) ready for PVC card printing.

## 🛠️ Tech Stack
* **Backend:** Python & Pillow (PIL) for image manipulation
* **APIs:** DigiLocker Partner API
